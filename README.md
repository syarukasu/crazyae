# CrazyAE (Forge 1.20.1 fork)

## English

This is syarukasu's source fork of [Beecube31's CrazyAE](https://github.com/beecupbe/crazyae), based on the upstream `1.20.1` branch at `c58566938bc950948fe09c7bf6e9b82b8395a19d`. The original author, contributor credits and mod metadata are retained. This fork does not claim authorship of CrazyAE and currently does not change its game behavior.

Original binary distribution: [CrazyAE on CurseForge](https://www.curseforge.com/minecraft/mc-mods/crazyae/files/9156669).

The separate [CrazyAE Big Crafting Capacity](https://github.com/syarukasu/crazy-ae-big-crafting-capacity) addon integrates the ME Crafting Units Combiner with ACO's exact BigInteger capacity checks. It requires ACO and CrazyAE and does not include either binary. Install that addon separately, not as a replacement for CrazyAE.

Upstream mod metadata declares MIT. Original credits: Beecube31, NekitFbetc and the upstream contributors. AE2 and other dependencies retain their own licenses.

## 日本語

Beecube31氏のCrazyAEを、元の`1.20.1`ブランチからフォークしたソース公開用リポジトリです。元作者・協力者の表記を維持し、CrazyAE自体の作者を名乗るものではありません。このフォークでは現在、ゲーム動作を変更していません。

CombinerのBigInteger容量対応は、別MODの[CrazyAE Big Crafting Capacity](https://github.com/syarukasu/crazy-ae-big-crafting-capacity)で行います。ACOとCrazyAEを前提に追加導入する互換MODで、CrazyAE本体の置き換えではありません。

CrazyAE本体の配布先は上記の元CurseForgeプロジェクトです。元のMODメタデータではライセンスはMITとされています。
